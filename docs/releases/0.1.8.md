## Install With BRAT

Add `https://github.com/marumimamori/spotlight-ex` using **BRAT: Add a beta plugin for testing**. Enable **Spotlight EX**, then follow **Settings → Spotlight EX → Setup**.

For manual installation, extract `spotlight-ex.zip` into `<Vault>/.obsidian/plugins/bases-spotlight-view-expanded/`. When updating, keep your existing plugin folder and `data.json`, and replace the release files. Reload Obsidian to see the new name and Setup tab.
